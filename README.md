# Saqib Hussnain - Portfolio

A clean, modern portfolio website showcasing my frontend development projects and skills.

## 🌐 Live Demo

Visit: [saqib-portfolio.netlify.app](https://saqib-portfo.netlify.app)

## 📋 About

I'm a Frontend Developer and Computer Science student currently learning backend development. This portfolio showcases four key projects built from scratch using HTML, CSS, and JavaScript.

## 🎯 Features

- **Responsive Design** — Mobile-first approach, works seamlessly on all devices
- **Smooth Navigation** — Single-page site with smooth scroll animations
- **Hamburger Menu** — Mobile-optimized navigation with toggle functionality
- **Project Showcase** — Interactive project cards with live demos and GitHub links
- **Skill Badges** — Clean display of technical skills
- **Contact Section** — Easy ways to connect via email, GitHub, and Instagram

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Design:** Fontshare (Clash Display, Satoshi fonts)
- **Icons:** Font Awesome 6
- **Hosting:** Netlify

## 💻 How to Use Locally

1. Clone the repository:
```bash
   git clone https://github.com/Saqib216/portfolio-website.git
   cd portfolio
```

2. Open `index.html` in your browser or use VS Code Live Server
